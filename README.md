# CO EPS - Course d'orientation

PWA hors ligne pour gérer une course d'orientation en 6e : pose des balises par les groupes, carte, chrono, vérification des codes, classement et export CSV.

Fichier unique `index.html` (codes des balises intégrés, issus de `8 Balises.pdf`). Utilisée par le professeur ou un élève dispensé.

Application : https://apps.outils-eps.fr/CO-EPS/

Fonctions : groupes d'élèves mixtes, 1 à 3 balises posées par groupe, placement des balises, du départ et de l'arrivée sur la carte, parcours de recherche différents par groupe (distances voisines), chrono avec pénalités, vérification des codes avec n° de poste, classement aux points, export CSV, mode élève. Version courante : voir le titre de l'appli.
